# Лабораторная работа №11 — шардирование (вариант 09, IoT-датчики)

Требуется Python 3.10+ (сторонние пакеты нужны только для plot_chart.py).

## Запуск в VS Code
1. File → Open Folder → выберите папку с файлами.
2. Откройте терминал (Ctrl+`) и выполните:
   python simulation.py
   python simulation_step4.py
   pip install matplotlib
   python plot_chart.py
(на Windows можно `py` вместо `python`; на Linux/macOS — `python3`)
3. Seed зафиксирован (random.seed(42)), повторный запуск даёт те же числа.
